## 这是一场什么比赛？

具身智能不止要“看懂”世界，也要能在物理世界中行动。赛事以前所未有的“**三项全球首例挑战**”，直指具身智能从训练走向真实应用的核心瓶颈。赛事将本体、算法、数据、仿真与安全评测置于同一真实任务闭环之中，不为单一本体预设标准答案，也不以理想环境掩盖真实难题。
