## 这是一场什么比赛？

具身智能不止要“看懂”世界，也要能在物理世界中行动。本赛题聚焦从多视角视频生成面向仿真的三维资产：几何、纹理、碰撞体、刚体与 USD 提交格式缺一不可。

这正好位于视觉理解、三维重建、生成式 AI、物理仿真和机器人学习的交叉点。无论你来自计算机视觉、图形学、机器人、强化学习，还是大模型方向，都可以在这里找到可落地的问题。
